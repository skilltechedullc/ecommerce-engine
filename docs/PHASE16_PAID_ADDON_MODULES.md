# Phase 16 Paid Add-On Modules

Status: commercial packaging is defined; several modules already have feature flags or foundations.

## Base Included

- Storefront, cart, checkout, secure Razorpay verification, admin products, admin orders, manual shipping, email notifications, and basic dashboard.
- WhatsApp contact/support link without automation.
- Theme preset and store configuration foundation.
- Product/order CSV export and product import validation.

## Paid Add-Ons

- WhatsApp store/order automation: Meta/Twilio setup, templates, order updates, and support workflows.
- AI chat/product assistant: product-aware customer help, store policy answers, and usage monitoring.
- Advanced analytics: channels, conversion, repeat purchase, best sellers, and product performance.
- Loyalty/referral: points, referral rewards, redemption rules, and anti-abuse checks.
- Product reviews: customer reviews, moderation, rating display, and abuse controls.
- Multi-language: translated storefront/admin copy and optional Arabic RTL QA.
- Multi-currency: currency display, pricing rules, payment gateway compatibility, and region QA.
- Shipping provider integration: Shiprocket, Delhivery, or custom courier APIs beyond manual fulfillment.
- Product import/export service: bulk catalog cleanup, CSV/XLSX import, image mapping, and handover support.
- Custom design: extra theme/layout work beyond standard presets.
- Maintenance: updates, monitoring, backups, support, and small change requests.

## Pricing Guardrails

- Keep setup pricing separate from monthly maintenance.
- Charge provider integrations separately because each client account has different credentials, API behavior, and support needs.
- Include a fixed training session in every paid build so owners know how to add products, process orders, and update statuses.
- Use Millco as Demo Store 001 for showing changes before client rollout.
