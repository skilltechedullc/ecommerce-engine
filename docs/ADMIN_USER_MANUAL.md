# Admin User Manual

This is the basic operating guide for store owners.

## Products

- Add products from Admin > Products.
- Use variants for weights, sizes, packs, or quantity options.
- Keep stock accurate before accepting orders.
- Deactivate a product instead of deleting it when it may appear in old orders.

## Orders

- Open Admin > Orders to see new orders.
- Check payment status before shipping.
- Move orders through the normal flow: pending, paid, processing, shipped, delivered.
- Use cancelled, refunded, return_requested, and returned only when the business process requires it.
- Add shipment details when tracking is available.

## Customers

- Use customer details only for fulfilling and supporting orders.
- Do not export or share customer data unless the client/store owner has a valid business reason.

## Daily Routine

- Check pending orders.
- Check low-stock alerts.
- Update order statuses.
- Confirm failed notifications and retry when needed.
- Add or update products before marketing campaigns.
