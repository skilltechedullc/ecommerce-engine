# Phase 10 Base Client Store Package

Status: base client store package is documented and mostly implemented in the current engine.

## Included In Base Package

- Storefront homepage.
- Product listing.
- Product detail.
- Cart.
- Razorpay checkout.
- Success page.
- Custom admin backend.
- Product management.
- Order management.
- Basic order workflow.
- Secure server-side Razorpay verification.
- Optional COD/manual payment mode behind `NEXT_PUBLIC_FEATURE_MANUAL_PAYMENTS`.
- Email order notifications through Resend.
- WhatsApp contact/support links without automation.
- Manual shipping/order processing.
- Basic dashboard for revenue, orders, low stock, and recent activity.
- Store branding/configuration through env/presets and admin settings draft foundation.

## Not Yet Included In Base Package

- Full client handover automation with generated admin credentials.

## Client Training Checklist

- How to log in to admin.
- How to add a product.
- How to add variants, price, stock, and images.
- How to deactivate a product.
- How to review orders.
- How to update order status.
- How to create a manual shipment.
- How to retry failed notifications.
- How to review store settings.

## Handover Packet

Each client handover should include:

- Store URL.
- Admin URL.
- Admin email.
- Temporary password.
- Support contact.
- Feature package purchased.
- Payment account owner.
- Supabase account owner.
- Hosting account owner.
- Domain owner.
- Basic operating guide.
